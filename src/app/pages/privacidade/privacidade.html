LGPD

Política de Privacidade

Esta página explica como o protótipo acadêmico AdotaSSA trata os dados inseridos pelo usuário.

1. Quais dados são utilizados?

Nome, e-mail e senha informados no cadastro. O projeto também pode armazenar publicações, imagens, mensagens e informações de animais inseridas pelo usuário.

2. Para que os dados são utilizados?

Somente para demonstrar as funcionalidades de cadastro, login, proteção de rotas, publicação, adoção e interação entre usuários dentro deste projeto acadêmico.

3. Onde os dados ficam armazenados?

Como o projeto não utiliza API nem banco de dados, os dados ficam no próprio navegador usando localStorage. A sessão de login utiliza sessionStorage.

4. Consentimento

O cadastro só é concluído quando o usuário marca o campo de consentimento referente a esta Política de Privacidade.

5. Direitos do usuário

Na página de perfil é possível consultar informações da conta, alterar a senha e excluir a conta cadastrada neste navegador. Ao limpar os dados do navegador, as informações locais também são removidas.

6. Limitações do protótipo

É um projeto acadêmico e não deve ser usado como sistema real de autenticação, pois não possui backend, criptografia de senha nem banco de dados.
