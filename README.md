# AdotaSSA

Protótipo acadêmico em Angular para adoção responsável e comunidade de proteção animal em Salvador.

## Como executar

1. Abra o CMD na pasta do projeto.
2. Rode `npm install`.
3. Rode `npm start` ou `npx ng serve`.
4. Acesse `http://localhost:4200`.

## O que o projeto possui

- Login e cadastro sem API, usando `localStorage` e `sessionStorage`.
- Consentimento LGPD e página de privacidade.
- Proteção de rotas com `authGuard`.
- Home responsiva com carrossel interativo.
- Página de adoção com filtros.
- Comunidade com curtidas e comentários.
- Página protegida para publicar pets e posts.
- Perfil com opção de encerrar sessão e excluir a conta local.

> Observação: como este é um protótipo Front-End sem backend, senhas e dados ficam apenas no navegador. Isso serve para demonstração acadêmica, não para produção real.
